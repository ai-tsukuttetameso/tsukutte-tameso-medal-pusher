# つくってためそ メダルの滝

～AIにメダルゲームを遊ばせたら、メダルは増える？～  
企画・実装 Claude ／ Codex ／ 第17回「AIでつくってためそ」

本作品は学習・検証目的の作品です。本物のメダルや景品とは関係ありません。

## 遊ぶ

公開ページ：https://ai-tsukuttetameso.github.io/tsukutte-tameso-medal-pusher/

`index.html` が入口です（同じフォルダの `pusher-core.js` を読み込みます）。HTML/CSS/JavaScriptのみで動き、外部通信・外部ライブラリ・ビルドは不要です。

## どんなゲーム？

- 二段式のメダルプッシャーです。左右の発射口から上段を狙ってメダルを飛ばし、上段から落ちたメダルが下段を押して、手前の黄色いふちから落ちたメダルが手持ちに戻ります。
- 色の違うボールが左右のゲートを通るとスロット、手前から落ちるとルーレットが回ります。
- 青・紫・虹の色メダルを手に入れると、景品や上位抽選などのイベントが起きます。
- ジャックポットは上限なしで育ちます。JPの額だけ、遊んだブラウザに保存されます。
- オート投入、速さの切り替え、一時停止があります。

## AIに遊ばせるには

台の中身は `pusher-core.js` にあり、Node.jsでも動きます。

```js
const P = require('./pusher-core.js');
const g = P.create(1, { MODE: 'normal' });
g.drop(0, 160);      // 左の発射口から x=160 を狙って1枚
g.advance(0.4);      // 0.4秒進める
console.log(g.state());
```
